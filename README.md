# COMP 584 - Responsive Flexbox Assignment

## The Reading Nook

This project demonstrates responsive layouts using CSS Flexbox.

The website includes six rows with different column arrangements, including a five-column layout.

CSS media queries adjust the layout for desktop, tablet, and mobile screens. The order property changes the arrangement of items in Row 5 on tablet screens.
